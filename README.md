# MediBuddy - AI Health Assistant

An AI-powered chatbot application offering quick health remedies and emergency medical guidance, with integrated hospital locator.

## About

Built for the Samadhan 1.0 National Level AI Innovation Hackathon. Ranked 12 out of 90 competing teams.

## Features

- AI chatbot for health remedies and medical guidance
- Nearby hospital and emergency services locator
- Multi-page Streamlit interface
- Modular, scalable architecture

## Tech Stack

- Python
- Streamlit
- Custom CSS

## Getting Started

```bash
git clone https://github.com/theinnocentboy/final-project-samadhan
cd final-project-samadhan
pip install -r requirements.txt
streamlit run app.py
```
